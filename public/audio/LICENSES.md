## Notes on candidates considered and rejected

- **Pixabay "Supermarket Ambience" (freesound_community, id 17419)** — good
  content but 3:34 long; would have produced an oversized file for no
  benefit over the shorter, equally usable `city-supermarket-71538` track,
  so the shorter one was used instead.
- **Pixabay "Background Calm" by VelarioMusic (id 585951)** — otherwise a
  good calm/modern-classical fit, but downloaded to 3.28 MB (256 kbps,
  1:47), over the 3 MB budget for this project; replaced with the smaller
  "Lounge Elevator Music" track above, which is also a closer match to
  "muzak-like" store background music.
- Freesound.org candidates were not used because direct file downloads
  there require an authenticated API key/login, which this task could not
  perform.
